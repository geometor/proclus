**Proclus Diadochus • Commentary on the First Book of Euclid's Elements • semantic digital archive**

Mission
-------

``geometor/proclus`` is part of the interconnected `GEOMETOR <https://geometor.com>`_ semantic digital archive. Proclus Diadochus's commentary is the richest ancient companion to Euclid's Elements, preserving Eudemus's lost history of geometry, the epistemology of mathematical imagination, and the axiomatic foundation of Greek mathematics. Within this archive, Proclus's monumental commentary is liberated from isolated print bounds into addressable semantic units, synchronized 4-track codices (Greek, English, Summary, Notes), calibrated vector diagrams, and cross-corpus citations speaking one shared geometric language.

Books in This Archive
---------------------

- `Commentary on the First Book of Euclid's Elements <https://geometor.github.io/proclus/in_euclidem/>`_ — In Primum Euclidis Elementorum Librum Commentarii (c. 470 AD / ed. Friedlein 1873 / Taylor 1792), providing seven canonical divisions across prologues, definitions, postulates, and propositions I.1–I.48 with Friedlein citation concordance.


Repository Contents
-------------------

- ``docsrc/`` — 4-track synchronized Book Codex tracks, concordance, glossary, and scholarly apparatus compiled by `PHOTON publish <https://github.com/photon-platform/publish>`_.
- ``resources/`` — Verified Friedlein Greek text, Taylor English translations, and citation concordance registries.
- ``src/geometor/proclus/`` — Python package and CLI tools for concordance verification and apparatus compilation.
