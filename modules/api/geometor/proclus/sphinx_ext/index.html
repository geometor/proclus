geometor.proclus.sphinx_ext¶

Runtime Sphinx & photon-platform/publish integration for GEOMETOR Proclus.

Registers the el (“Greek (1873)”) companion track in photon_platform.publish.book at build time (without modifying photon-platform/publish) and configures offline-safe local intersphinx inventories for euclid, elements, and hoenen.
